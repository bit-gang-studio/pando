# Pando

The worktree-native Git client. Open source, cross-platform.

**Status:** pre-alpha. Nothing to install yet.

## Develop

Needs Rust (rustup), Node 22, pnpm, and `just`.

```sh
just setup
just dev          # desktop app
just cli doctor   # CLI
just test
```
